DSA Lab

Política de privacidad

Versión 1.0 · Última revisión: 8 de noviembre de 2026

DSA Lab es un proyecto educativo independiente. Puedes usar el laboratorio sin crear una cuenta. Los reportes son voluntarios: no envíes contraseñas, claves, documentos de identidad, datos sensibles ni información de otras personas.

Lo que queda en tu navegador

Los datos que introduces para ejecutar las visualizaciones se procesan en el navegador. Para recordar tus preferencias entre visitas, el sitio guarda en el almacenamiento local el idioma, las opciones de accesibilidad, el algoritmo seleccionado, la velocidad de reproducción, el modo de código, si ya viste la introducción y si el menú lateral está plegado.

También se guardan el progreso de los desafíos, el historial de resultados y los bloqueos temporales de las pruebas. Puedes borrar estos datos desde la configuración del navegador. Esto restablece las preferencias y el progreso guardados en ese navegador, pero no elimina los reportes que ya enviaste.

Visitas, rendimiento y seguridad

El sitio usa Vercel Web Analytics y Speed Insights para medir visitas y rendimiento. Las mediciones pueden incluir la página visitada, el navegador, el tipo de dispositivo, la ubicación aproximada y tiempos de carga. No las usamos para publicidad personalizada. Los servicios que alojan y protegen el sitio pueden tratar datos técnicos de conexión, como la dirección IP, para servir páginas, diagnosticar fallos y prevenir abusos.

Formulario de reportes y verificación

Al abrir el formulario se contacta con Railway para comprobar la disponibilidad de la API y se carga la verificación de Cloudflare Turnstile. Estas conexiones pueden tratar datos técnicos aunque no envíes el reporte. El contenido de los campos se envía a la API cuando pulsas «Enviar reporte».

Al enviar un reporte compartes el nombre que escribas (puede ser un alias), el correo si lo incluyes, el asunto, el tipo de problema, la descripción y los pasos que agregues. También se envían la sección, el origen y la ruta de la página, y la información del navegador. La URL de diagnóstico excluye credenciales, parámetros y fragmentos.

Para enviar necesitas un nombre o alias de al menos dos caracteres, un resumen, un tipo de problema y una descripción de al menos diez caracteres. El correo y los pasos para reproducirlo son opcionales. «Copiar» coloca el texto del reporte en el portapapeles del dispositivo; no lo envía por sí solo.

Cloudflare Turnstile usa señales técnicas del navegador y de la conexión para detectar envíos automatizados. La API en Railway usa la dirección IP para limitar abusos y la envía a Cloudflare al verificar el token de seguridad. Resend entrega el reporte al buzón de DSA Lab. El correo opcional se usa para responder a tu reporte, no para inscribirte en una lista de difusión.

Acceso, uso y conservación

No publicamos reportes ni vendemos los datos que nos envías. Los usamos para investigar el problema, responder si dejaste un correo y proteger el servicio. Los proveedores mencionados intervienen para prestar esas funciones y pueden procesar datos fuera de tu país.

La API no guarda una base de datos de reportes. Los correos de reportes se eliminan del buzón como máximo 90 días después de cerrar el caso, salvo que exista una obligación legal de conservarlos durante más tiempo. El borrado del buzón es manual. Puedes solicitar la eliminación antes de ese plazo por el canal indicado más abajo. Las copias y los registros técnicos que mantengan los proveedores tienen sus propios plazos.

Un caso se cierra cuando se resuelve o se decide terminar su atención. Los casos abiertos se revisan periódicamente para no conservar datos que ya no sean necesarios. La eliminación del buzón no equivale a borrar de inmediato las copias de respaldo de los proveedores.

Consultas y solicitudes de privacidad

Para consultar sobre tus datos o solicitar acceso, corrección, eliminación u otro derecho aplicable, vuelve a DSA Lab, abre «Informar un problema», selecciona «Otro problema» y escribe «Solicitud de privacidad» como resumen.

Explica qué necesitas y deja un correo para recibir respuesta. Si la solicitud se refiere a un reporte anterior, indica su asunto y fecha aproximada si los recuerdas. Podemos necesitar verificar que los datos te corresponden antes de entregarlos o modificarlos. No adjuntes documentos de identidad ni repitas información sensible en el formulario.
